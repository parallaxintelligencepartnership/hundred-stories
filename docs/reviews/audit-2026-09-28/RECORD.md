### Refuted
- Lane C S4, hotel guests who give up counted as tenants who moved out: Evidence: giveUp only fires for a sim in state 'waiting', and every guest path (check-in, checkout, sendAway, moveOut) clears inRoomId or exits before that state is reached, so checkOutOfHotel with a set leaveReason never runs; a 6-day, 19-floor probe logged 210 give-ups against 0 counted move-outs.
- Lane B S1 (partial): a condo reselling after its owners move out for "no way in" is not a defect on its own. Evidence: the guide, README and DESIGN.md all document a vacated condo going back up for sale, matching the same code path as a low-rating move-out; the free-car-setting trigger that causes the move-out is filed below as a question, not a finding.
- Lane F1 S5's claim that the car floor sign shows the wrong floor "until 75% of the way down": Evidence: car.y is never fractional (it moves whole floors per tick), so no 75%-of-the-way arithmetic exists; the real defect, confirmed in a different form, is that the sign labels the departure floor rather than the crossing's direction during the whole first half of a move to B1.

- Should a tower opened by switching (Today's tower, a friend's tower, Open a saved file, New game) frame the whole tower the way the game does at boot, instead of always resetting the camera to zoom 1 at the middle of the lot? (lane F1)
