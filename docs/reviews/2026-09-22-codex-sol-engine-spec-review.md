# Second opinion: engine round spec review (Codex GPT-5.6-Sol, high effort)

Date: 2026-09-22. Read-only review of docs/reviews/2026-09-22-engine-round-spec.md as first written, against src/game/game.ts, src/render/renderer.ts and tests/game/loop.test.ts. Verdict: the frame-driven loop and the gradient cleanup hold up; the interpolation and teleport handling did not. Every point below was checked against the code by the orchestrator before the spec was revised; the revised spec supersedes the version reviewed here.

1. Hidden tabs and autosave. Hidden time beyond one second per timer callback is already discarded by the dt cap in step, so hidden progress is best effort today; the spec should say so, keep maybeAutosave inside the shared advance, gate both drivers symmetrically, and add and remove the visibility listener in start and stop. Accepted.
2. Fractional alpha. Wrong for multi-tick frames: the renderer's px is the previous rendered target, not the position before the last simulation tick, so alpha would be applied across the whole batch; and the settle rule snaps unfinished interpolation when the next batch leaves the target unchanged. Fix: snapshot positions immediately before the final tick of the batch and interpolate those to the current state; the settle rule then goes away. Accepted.
3. Teleport threshold. Scaling it by batch size can hide a real discontinuity, and the proposed test made a 13 tile teleport lerp at two ticks. Loads also replace world (game.ts importSave) without clearing the renderer's interpolation maps (simInterp and the car map). Fix: keep the per-tick threshold, reset interpolation on load and new game. Accepted; with point 2 the scaling is unnecessary anyway.
4. Tests. The proposed 4x daytime test allows no multi-tick frames and only asserts the formula. Add a night 4x test with alternating five and six tick batches asserting rendered positions stay monotonic and near uniform, including a stationary batch after. Accepted, via a pure interpolation module so it needs no stub renderer.
5. Spec and code mismatches. The stepOnce tests inject no hidden, so the proposed default (visible in node) would make them no-ops; and 30 s at 1x is 300 game minutes, not 30. Accepted: the default treats a missing document as hidden, and the manual check says 300.
