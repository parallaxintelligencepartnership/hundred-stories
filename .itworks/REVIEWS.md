### Refuted
- Determinism of the sim: same seed replays identically. Two independent builds of one tower run two game days both hash 49f1915d; seed 778 hashes 128f0842; `npx vitest run tests/scenarios/growth.test.ts` run twice was 3 passed both times, including its own hashWorld(twin) === hashWorld(world) assertion at growth.test.ts:197.
- Sim purity: `grep -rn "Date\.\|Date(\|Math\.random\|window\.\|document\.\|localStorage\|performance\.\|pixi" src/sim/` returns only the three comment lines that state the rule. The only Date read in the whole of src is the default seed in main.ts:25, outside the sim.
- Secrets anywhere: `grep -rEn -f references/secret-patterns.grep` over src, public, dist and index.html, over the whole tree, and over `git log --all -p` all return nothing; `gitleaks detect --source . --no-banner` scanned 41 commits and found no leaks; `git ls-files | grep -E "(^|/)\.env|\.pem$|credentials"` is empty and .gitignore covers .env and .env.*.
- PixiJS blob workers blocked by worker-src 'self': the build contains no `new Worker` and no WorkerManager at all. The single URL.createObjectURL in dist is the save export anchor from src/ui/panels.ts:508, which is a download, not a worker, and no CSP directive governs it.
- CSP drift between the two hosting paths: the CSP strings in public/_headers and deploy/nginx.conf are byte identical, and dist/_headers is identical to public/_headers after a build.
- Google Fonts blocked by the policy: style-src carries https://fonts.googleapis.com and font-src carries https://fonts.gstatic.com, so the runtime link element and its woff2 files are both permitted. The service worker, registerSW.js and the manifest are all same origin and covered by script-src, worker-src and manifest-src 'self'.
- Dev only code in the bundle: `grep -rl "bootSmoke\|buildDemoWorld" dist/` returns nothing; the import is gated on import.meta.env.DEV at src/main.ts:8. The Checkpoint 1 finding stays closed.
