# Map

## Run
npm run dev (vite; landing on http://localhost:5173, the game on /play/); npm run build (tsc --noEmit && vite build, the web edition into dist) then npm run preview; build:demo (VITE_EDITION=demo, the capped demo, also into dist) and build:full; build:app (the game page alone into dist-app for the shells), cap:sync (build:app then cap sync), npx tauri build [--features steam] from the root; no env vars needed (the scripts set VITE_EDITION)

## Test
npm test (vitest run); one file: npx vitest run <path>; npm run typecheck (tsc --noEmit)
audio gate: npm run audio:samples (six presets through headless Chrome) then node scripts/analyze-audio-samples.mjs docs/reviews/audio-samples-2026-09-23/*.wav, every line PASS or SKIP; benchmarks: scripts/bench/README.md (npx vite-node@6.0.0 scripts/bench/bench3.ts prints a 09:00 and a `<label>-evening` 17:30 row per tower; scripts/bench/hash.ts prints the six hashes a performance change must not move)
